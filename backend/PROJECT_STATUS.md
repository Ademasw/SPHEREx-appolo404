## 1. Главная цель

Создать публичный веб-сервис, в котором пользователь выбирает участок неба
или известный объект и сравнивает реальные наблюдения SPHEREx по датам.
Сервис должен помогать замечать движение объектов и изменение яркости,
показывая происхождение данных, диапазон наблюдения и ограничения качества.

Конечный сценарий:

**Название или RA/Dec → поиск наблюдений → подготовка данных → анимация
и сравнение эпох → понятное объяснение обнаруженных изменений.**

Найти новую планету для выполнения задания не требуется. Нужен работающий
инструмент, который позволяет людям исследовать изменения неба.

## 2. Что уже сделано

### Сервер и интерфейс

- Создано изолированное окружение Python и зависимости проекта.
- Реализован сервер FastAPI и выдача подготовленных изображений и метаданных.
- Создан React-плеер: воспроизведение, пауза, смена кадров и выбор даты.
- Добавлены скорость переключения, масштаб, контраст и инверсия.
- Набор наблюдений и выбранный кадр сохраняются в URL.
- Есть ссылки на исходные научные файлы и пояснения об обработке.
- Собранный интерфейс обслуживается тем же FastAPI.
- Проверена работа в браузере, исправлено расположение кнопок на узком экране.

### Получение данных

- Подключён официальный архив NASA/IPAC IRSA через SIA API и Astroquery.
- Выполняется поиск реальных наблюдений по координатам с выбором релиза.
- Реализована загрузка небольших FITS-вырезок, кэширование и повторы запросов.
- Из-за повторяющихся HTTP 503 сервиса вырезок добавлен облачный путь:
  официальные bucket/key получаются из IRSA SIA `cloud_access`.
- Astropy и fsspec читают нужные секции облачных FITS без скачивания полных файлов.
- Сохраняются исходные ссылки, идентификаторы, даты и контрольные суммы кэша.

### Каталог целей и обработка

- В SIMBAD найдены все пять тестовых целей: Barnard's Star, Epsilon Indi B,
  WISE 0855, RW Aurigae, R Draconis.
- Сохранены каталожные координаты, собственные движения и ссылки на источники.
- Эпоха J2000 проверяется по метаданным координатных столбцов.
- Добавлена оценка положения к J2026 по собственному движению.
- Проверены IMAGE, FLAGS, VARIANCE, ZODI и спектральная WCS.
- Изображения совмещаются на общей небесной сетке.
- Учитывается часть флагов качества; информационный флаг SOURCE не удаляется.
- Длины волн проверяются у положения объекта и по выходным пикселям.
- Используется общая шкала яркости для сопоставимых кадров.
- Модель зодиакального фона ZODI вычитается после проверки совпадения сеток.
- Добавлено объединение спектрально совместимых повторов одной эпохи
  с весами, обратными поставляемой пиксельной дисперсии.

### Текущий основной набор: Epsilon Indi B

- Детектор: **SPHEREx D3**, релиз **DR1**.
- Диапазон: около **1,9789 мкм**.
- Эпоха 2025: наблюдение **29 апреля 2025 года**.
- Эпоха 2026: объединены наблюдения **29 апреля и 4 мая 2026 года**.
- Поле зрения: **3 угловые минуты**, сетка **30 × 30 пикселей**.
- Общая пригодная область: **895 из 900 пикселей — 99,44%**.
- Осталось **5 пропусков**, которые не заменяются выдуманными значениями.
- Оранжевый круг фиксирован относительно неба и не перемещается вслед
  за каталожным прогнозом.

Расчётное смещение по собственному движению около **4,68″** — это прогноз
из каталога, **не измеренное по изображениям движение**.

### Что исправлено с фиолетовыми пикселями

Фиолетовый был диагностическим цветом исключённых пикселей, а не свойством неба.
В прежней паре исключались 30/900 пикселей. После выбора другого близкого
диапазона и добавления реального повторного наблюдения осталось 5/900.

В обычном просмотре пропуски нейтрально-серые. Для Epsilon есть отдельная
янтарная маска `Show data-quality mask`. Численные маски сохраняются;
интерполяция отсутствующих измерений не применяется.

## 4. Чего пока нет

- Надёжно измеренного движения с оценкой погрешности.
- Регистрации по стабильным полевым звёздам и согласования PSF.
- Поправки на параллакс наблюдателя и полноценной модели видимого положения.
- Рабочего пользовательского поиска произвольных координат с подготовкой кадров.
- Очереди обработки с прогрессом и ограничениями размера запросов.
- Проверенного сценария просмотра для всех пяти целей.
- Публичного развёртывания: сейчас приложение работает локально.
- Спектров по клику, наложений Gaia/WISE и научно проверенных разностных кадров.

Наличие красивого плеера или сильного сигнала само по себе не подтверждает
движение и тем более открытие нового объекта.

## 5. Ближайшие шаги — в порядке приоритета

1. **Измерить положение Epsilon Indi B на исходных пикселях.**
   Подобрать метод определения центра, проверить влияние маски и PSF,
   получить погрешность. Не использовать положение круга как измерение.
2. **Проверить стабильные источники вокруг.**
   Оценить смещение и другие ошибки совмещения всего поля, чтобы не принять
   ошибку координатной привязки за движение цели.
3. **Сопоставить измерения разных эпох.**
   Учесть необходимые астрометрические поправки, сравнить результат с
   каталогом. Если значимости недостаточно, явно сообщить об этом.
4. **Сделать законченный демонстрационный сценарий.**
   Две даты, понятная отметка источника, отдельно прогноз и измерение,
   пояснение результата и качества. Доработать сравнение рядом и переключение.
5. **Подключить ввод координат к реальной обработке.**
   Поиск наблюдений → выбор сопоставимых данных → задача подготовки →
   прогресс → результат из кэша. Не ограничиваться заранее подготовленными кадрами.

Критерий ближайшего успеха: пользователь понимает, где объект, какие даты
сравниваются, что измерено и насколько достоверен вывод.

## 6. Глобальный план до готового сервиса

| Этап | Результат | Критерий готовности |
|---|---|---|
| Научный сценарий | Один объект с проверенным сравнением | Измерение и его ограничения объяснимы |
| Универсальный конвейер | Поиск, загрузка, качество, совмещение, эпохи | Работает по введённым координатам |
| Основная версия | Удобный плеер и пять тестовых целей | Для каждой цели есть результат или понятное объяснение ограничения |
| Надёжность | Кэш, фоновые задачи, ошибки, ограничения | Повторный запрос быстрый; сбой архива не ломает интерфейс |
| Размещение и хакатон | Публичная ссылка, демо, документация | Другой человек воспроизводит основной сценарий |
| Расширения | Разности, спектры, Gaia/WISE | Каждая функция проверена на реальных данных |

102 спектральных канала — направление для дальнейшей работы со спектрами.
Один пиксель отдельного спектрального снимка не содержит автоматически
102 измерений яркости: спектр собирается из множества наблюдений.

## 7. Хранение и воспроизведение

- Код, документация, зависимости и тесты хранятся в Git.
- `.venv`, `node_modules`, собранный frontend и `data/` исключены из Git.
- В `data/` лежат метаданные, каталоги, FITS, облачные NPZ-секции, PNG и манифесты.
- Для повторной подготовки нужны доступ к интернету и выполнение скриптов;
  после клонирования научный кэш сам по себе не появляется.
- Инструкции установки и запуска: [README.md](README.md).

Основная последовательность после установки зависимостей:

```powershell
.\.venv\Scripts\python.exe -m scripts.audit_targets
.\.venv\Scripts\python.exe -m scripts.probe_cloud
.\.venv\Scripts\python.exe -m scripts.prepare_epsilon
cd frontend
npm install
npm run build
cd ..
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Локальный интерфейс: http://127.0.0.1:8000/?mode=epsilon.
API-документация: http://127.0.0.1:8000/docs.
