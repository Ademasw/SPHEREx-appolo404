# Отчёт о текущей реализации Apollo 404

Дата: 14 ноября 2026 года. Ветка: `dev`.

## Что добавлено после предыдущей отправки

### Измерение Epsilon Indi B

- Определение фотоцентра на исходных пикселях основных экспозиций,
  без использования PNG, положения круга или стека для просмотра.
- Поправка на сдвиг поля по соседним источникам.
- Проверка чувствительности результата к радиусу апертуры.
- Проверка опор по официальному каталогу Gaia DR3 ESA с переносом координат
  к эпохе наблюдения и учётом собственных движений опор.
- Найдено 139 каталожных источников в области; финальная поправка использует
  три пригодные каталожные опоры.
- Текущая предварительная оценка: **4,29″**, компоненты **+3,31″ на восток
  и −2,74″ на север**. Разброс опор по осям около **0,70″ / 0,66″**.
- Каталожный прогноз для сравнения: около **4,68″**.
- JSON-отчёт доступен через `/api/epsilon/motion`; результат отображается
  в интерфейсе с явной отметкой предварительного характера.

Первая оценка 4,93″ относилась к этапу без каталожной проверки. Она сохранена
в отчётах как промежуточная и не должна подменять актуальную оценку Gaia.
PSF, смешение источников, параллакс и полный бюджет систематических ошибок
ещё не проверены. Подтверждённое собственное движение не заявляется.

### Рабочий поиск по координатам

- Ввод RA/Dec, размера поля 1.2–6 угловых минут и детектора D1–D6.
- Реальный поиск метаданных IRSA и чтение нужных секций облачных FITS.
- Подготовка до трёх экспозиций, выбранных по времени, с маской качества,
  общей пространственной сеткой и общей шкалой отображения.
- Фоновая очередь: два исполнителя, до четырёх задач суммарно.
- Отображение прогресса, ошибок и пустых результатов.
- Дисковый кэш успешных запросов на 24 часа; повторный поиск использует его.
- Ссылка с ID задачи и выбранным кадром восстанавливает результат.
- Исправлены конкурирующее чтение/запись статуса на Windows и повторный
  запуск того же запроса в интерфейсе.

Маршруты:

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/jobs` | Создать задачу или получить ID кэшированного запроса |
| GET | `/api/jobs/{id}` | Статус, прогресс, ошибка или ссылка на результат |
| GET | `/api/jobs/{id}/result` | Метаданные подготовленной последовательности |
| GET | `/api/jobs/{id}/frames/{index}` | PNG реального наблюдения |

Поиск произвольных координат пока **исследовательский**: длины волн между
кадрами могут различаться. Он не идентифицирует объекты, не согласует
спектральные каналы автоматически и не измеряет движение. Отдельный
проверяемый сценарий Epsilon остаётся самостоятельным набором.

Живой запрос для области Epsilon вернул кадры 29 апреля 2025,
29 сентября 2025 и 4 мая 2026. Это отдельный пользовательский запрос,
а не научно согласованная пара измерительного сценария.

## Хранение и запуск

В репозитории находятся исходники, тесты, зависимости и отчёты. Научный
кэш `data/`, `.venv`, `node_modules` и `frontend/dist` исключены из Git.
После клонирования данные нужно подготовить скриптами или запросить
через интерфейс. Инструкции: [README](../README.md).

Очередь рассчитана на один процесс Uvicorn. Незавершённая задача после
перезапуска сообщает об ошибке; её можно отправить повторно. Распределённая
очередь, авторизация и публичное размещение пока не реализованы.
