# Пропуски данных: исправление отображения и реальное покрытие

Фиолетовый цвет был диагностической заливкой приложения, не цветом
наблюдаемого неба. В исходной паре 1.8049 мкм исключались 30/900 пикселей:
по 15 из каждого кадра, без пропусков покрытия и без спектрального отсева.

Теперь обычное отображение всех подготовленных наборов — оттенки серого.
Отсутствующие измерения остаются invalid/NaN и отмечаются нейтральной
шахматной заливкой. У Epsilon доступна отдельная янтарная маска качества
`?mask=true` / Show data-quality mask. Цвет маски не меняет измерения.
Интерполяция и генерация значений для отсутствующих измерений не применяются.

Помимо отображения улучшено реальное покрытие. Заголовки всех 60 D3
наблюдений Epsilon проверены через официальную облачную копию. Выбрана
пара около 1.9789 мкм с повторным покрытием эпохи 2026 года:

- 2025-04-29 16:19:20 UTC: 2025W18_1B_0175_2;
- 2026-04-29 05:32:08 UTC: 2026W18_1A_0457_1;
- повтор 2026-05-04 02:48:24 UTC: 2026W19_1A_0041_1.

Для эпохи 2026 совмещены реальные наблюдения в пределах 7 дней с близкими
длинами волн. На каждом пикселе проверяется спектральная совместимость;
вес — обратная поставляемая пиксельная дисперсия. Плохие пиксели имеют
нулевой вес. Значения другого года не используются для заполнения эпохи.
Повтор дал пригодные измерения для 70 пикселей, отсутствовавших у основной
экспозиции этой новой пары. Итог общей сетки — 895/900 пригодных пикселей
(99.44%), осталось 5 пропусков. Переход 30→5 достигнут выбором другой
сопоставимой полосы и использованием реального повторного наблюдения.

Это предварительный стек для просмотра. PSF и ковариация после nearest-
neighbor ресэмплинга не моделируются. Эпоха 2026 теперь охватывает несколько
дней, что явно указано в интерфейсе и списке contributors. Движение ещё
не измерено; S/N в интерфейсе относится к основной экспозиции.
