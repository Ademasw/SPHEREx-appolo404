# Каталог и первое переключение эпох

Добавлен воспроизводимый аудит пяти целей через SIMBAD и IRSA.
SIMBAD CDS TAP вернул 404; использовано официальное зеркало Harvard.
Исходные таблицы с метаданными единиц и эпохи сохранены в data/catalog/*.ecsv.

Эпоха J2000 подтверждена из utype координатных колонок. Собственное движение
пересчитано к J2026 с помощью Astropy, с учётом cos(dec) в pmra. Расчёт не
учитывает параллакс наблюдателя, лучевую скорость и орбитальное движение
компонентов. Это оценка центра поиска, а не точная видимая позиция.

Для WISE 0855 оценка J2026: RA 133.7597653°, Dec −7.2421822°.
Она отличается от координат в примере задания. Ранее подготовленные
изображения продолжают использовать центр из задания и не маркируют
источник как обнаруженный.

Из уже скачанных кадров выбрана пара 2025-05-05 и 2026-05-11:
центральные длины волн 4.96842 и 4.96838 мкм. Дополнительно проверено
согласование длин волн для каждого отображаемого пикселя (допуск —
четверть меньшей центральной полосы). Общая пригодная область — 85.2% сетки.
После проверки совпадения сеток IMAGE и ZODI вычтена поставляемая модель
зодиакального фона. Две PNG и blink.gif используют одну шкалу отображения.

Сравнение остаётся диагностическим: PSF не согласованы, маска артефактов
не полна, движение и обнаружение объекта не подтверждены.

Покрытие DR1 по оценённым центрам J2026: Barnard — 239 записей,
Epsilon Indi B — 338, WISE 0855 — 258, RW Aur — 226, R Dra — 413.
Это покрытие фиксированных координат, а не подтверждение обнаружений.

Результаты доступны через /api/comparison и /api/comparison/frames/{index}.
Оба кадра просмотрены визуально. Проверки охватывают API, координаты,
маскирование и сохранение пикселей с информационным флагом SOURCE.

видимость источников, подобрать спектрально сопоставимые наблюдения
