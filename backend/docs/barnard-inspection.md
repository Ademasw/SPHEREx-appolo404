# Звезда Барнарда: источник виден, движение не измерено

Вместо прежней области WISE проверена область звезды Барнарда вокруг
расчётного положения J2026. Координаты SIMBAD J2000 перенесены с учётом
собственного движения; параллакс наблюдателя и лучевая скорость не учтены.
Запросы вырезок: 0.05° (3′), DR1, D1. Исходные FITS сохранены в data/cutouts.

Успешно получены и визуально просмотрены:

| UTC | λ в расчётном положении | Пригодные пиксели в радиусе 3 px |
|---|---:|---:|
| 2025-08-27 05:06:02 | 0.75011 мкм | 7 / 27 |
| 2026-03-11 16:49:49 | 0.88329 мкм | 0 / 29 |

На кадрах присутствует яркий источник, окружающий расчётное положение.
Оранжевый круг — расчёт, а не измерение центра. Фиолетовый центр — пиксели,
исключённые по флагам OVERFLOW/SUR_ERROR; рядом также стоят BLOOM и TRANSIENT.
Яркий источник уверенно виден как структура, но точное движение по этим
кадрам не измерено. Ожидаемый сдвиг по каталожному собственному движению —
5.59″ (около 0.90 пикселя), а длины волн существенно различаются.

Каждый кадр имеет собственное растяжение для осмотра: сравнивать яркость нельзя.
Это режим проверки положения и качества, не научная анимация движения.

Несколько других запрошенных вырезок (поздний D1, первый D3, первый D1
следующей эпохи) после повторов вернули IRSA HTTP 503. Они не заменены
синтетическими данными. Скрипт инспекции сохраняет успешные результаты,
а ошибки пишет отдельно и продолжает следующие наблюдения.

## Воспроизведение

```
python -m scripts.audit_targets
python -m scripts.inspect_barnard
python -m scripts.prepare_barnard_view
```

Альтернативный выбор первого кадра следующей эпохи:
`python -m scripts.inspect_barnard --late-first --detector D1`.
Успешные кадры и отчёт сохраняются в data/barnard-matched; это отдельный
эксперимент, не замена основного набора. Его запрос пока вернул 503.

Новый режим `/api/barnard` в плеере показывает источник, положение и флаги.
Следующий научный шаг — получить спектрально сопоставимые кадры с пригодным
центром или проверить метод подгонки ненасыщенных крыльев. Если качество
звезды Барнарда этого не позволяет, перейти к другой тестовой цели и явно
сохранить ограничение для Барнарда.
