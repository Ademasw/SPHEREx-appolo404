# Epsilon Indi B: первая пара с пригодным центром

## Полученный результат

Ниже описана первая пара. Актуальный набор после улучшения пропусков
использует 1.9789 мкм и повторное покрытие эпохи 2026:
см. [data-gap-fix.md](data-gap-fix.md).

Подобраны два реальных наблюдения SPHEREx DR1, D3:

| UTC | ID | λ у расчётного положения |
|---|---|---:|
| 2025-04-29 03:11:38.371 | 2025W18_1B_0091_2 | 1.804906665 мкм |
| 2026-04-29 03:53:51.187 | 2026W18_1A_0444_1 | 1.804958382 мкм |

Оба локальных ядра пригодны по используемой маске (100% пикселей в радиусе
1.5 px). Проверка показывает компактный сильный сигнал около расчётной
позиции. Пиковое отношение сигнала над фоном к поставляемой пиксельной
погрешности — 87.8 и 90.8. Это диагностическая проверка, не интегральная
статистическая значимость обнаружения и не измерение движения.

Общая пригодная спектрально сопоставимая область — 96.7% выходной сетки.
Кадры приведены к общей WCS, используется одна asinh-шкала. Перед этим
вычтена поставляемая модель ZODI после проверки совпадения координатных сеток.
Для каждого выходного пикселя проверена близость длин волн с допуском
четверть меньшей центральной полосы. Оранжевый круг стоит на одних и тех
же небесных координатах в обоих кадрах; он не двигается вслед за каталогом.

## Как получены данные

Из-за повторяющихся HTTP 503 сервиса вырезок использована официальная
облачная копия. Ссылки на bucket/key получены через IRSA SIA cloud_access.
Astropy + fsspec читают заголовки и только нужные секции IMAGE, FLAGS,
VARIANCE и ZODI, а также спектральную таблицу. Полные FITS не скачиваются.

Секции без интерполяции, их заголовки, спектральные карты и начало секции
на исходном детекторе сохраняются в NPZ (без pickle), вместе с исходными
URL и SHA256 кэша. Это локальный научный кэш, не полный исходный MEF.

```
python -m scripts.audit_targets
python -m scripts.probe_cloud
python -m scripts.prepare_epsilon
```

Результаты: data/epsilon-cloud/manifest.json, 0.png, 1.png, comparison.png,
blink.gif и NPZ-секции. /api/epsilon и /api/epsilon/frames/{index} обслуживают
этот набор. Плеер по умолчанию открывает ?mode=epsilon.

## Ограничения

Пока не выполнены согласование PSF, регистрация по полевым звёздам,
подгонка центра с оценкой погрешностей и поправка на параллакс наблюдателя.
Поэтому движение по этой паре ещё не подтверждено. Разрешение SPHEREx
не позволяет на этих кадрах разделить компоненты тесной системы.

Следующий этап — оценка положения источника и стабильных полевых объектов
на исходных пикселях с проверкой смещений и систематических ошибок.
